# NorthStar Database and Analytics Project

This repository contains the Google Colab notebook for the Databases and Analytics assignment based on the NorthStar Urban Mobility and Logistics case study.

The project analyses operational performance using Python, SQL within R and MongoDB Atlas. The main focus is on delivery delays, customer complaints, hub performance, MongoDB CRUD operations and query optimisation.

## Tools Used

- Google Colab
- Python
- Pandas
- Matplotlib
- R
- SQL within R
- MongoDB Atlas
- PyMongo

## Main Work Completed

- Imported and prepared the NorthStar dataset
- Checked dataset structure and data quality
- Calculated delivery duration, delay status and delay hours
- Created KPI summary
- Produced Python visualisations
- Ran SQL queries within R
- Connected Google Colab to MongoDB Atlas
- Performed MongoDB CRUD operations
- Used MongoDB aggregation
- Created indexes for query optimisation
